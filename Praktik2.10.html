Teks Formatting untuk teks dari komputer

Perintah javascript untuk menapilkan teks ke consol adalah consol.log. Kita juga bisa menampilkan isi variabel dengan fungsi ini. Misalnya kita punya variabel name maka kode programnya bisa ditulis seperti ini: 

        var name = "KELAS X PPLG 2"
        console.log(name)
Maka hasil output: KELAS X PPLG 2

Untuk menjalankan ulang program, lakukan refresh dengan menekan tombol F5
